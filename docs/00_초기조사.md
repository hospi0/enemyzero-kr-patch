## 디스크
- 4장 모두 ISO9660, 루트 폴더에 거의 다 있음. 꺼내기: `python tools/disc.py dump <장>` (AVI 빼고 work/disc0~3 에 꺼냄)
- 실행 파일 0.BIN(457,084 B, 4장 같음). 장마다 AVI(동영상) 대부분 + AIF(소리) + DGT/DG2(그림) + TEX/PAL/MDL/MAP(3D)
- 디스크 0 = 오프닝 디스크(트레이닝 모드·오프닝 동영상, BMP/ 폴더 83장 640×480)
