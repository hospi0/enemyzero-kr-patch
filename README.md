# 에너미 제로 한글 패치

세가 새턴 일본판 **에너미 제로(Enemy Zero, 사타코레 4장)** 한글 패치입니다.

## 내려받기

[릴리즈](https://github.com/hospi0/enemyzero-kr-patch/releases/latest)에서 `EnemyZero_KR_v0.9.zip` 을 받아
압축 안 `readme.txt` 대로 디스크마다 원본 트랙 1에 적용하세요.

## 바뀌는 것

- 게임 안 음성 대사 한글 자막
- 동영상 대사 한글 자막(화상전화 포함)
- 저장·디스크 안내, 데이터베이스, 문서, 트레이닝 등 글자 그림

## 알려진 점

- 시험 단계 패치입니다. 잘못된 곳을 알려 주시면 고치겠습니다.
- 음성은 원본 일본어 그대로이고 자막으로만 옮겼습니다.

## 저장소 구성

- `tools/` — 추출·받아쓰기·자막 훅·동영상 자막 부호화·그림·디스크 빌드·배포 도구
- `data/번역/` — 음성 자막 번역 · `data/그림/` — 그림 글자 번역
- `docs/` — 조사 기록
